# 🐔 Fowlgen Wars

**Fowlgen Wars** é um jogo estratégico mobile desenvolvido em **Unity (C#)**, onde galinhas entram em batalhas táticas em tempo real.

## 🎮 Sobre o Jogo
Liderando seu exército de galinhas em combates dinâmicos, gerando recursos e desenvolvendo estratégias para vencer os seus oponentes. O jogo combina mecânicas de estratégia com uma estética divertida e imersiva.

## 🛠️ Tecnologias e Ferramentas
* **Engine:** Unity
* **Linguagem:** C#
* **Gestão de Tarefas / Ágil:** Trello
* **Plataforma Alvo:** Mobile (Android / iOS)

## 🏗️ Arquitetura e Desenvolvimento
* **Back-end do Jogo:** Desenvolvido em C# com Unity para gerir a lógica de combate, estados das unidades e inteligência artificial.
* **Planeamento de Sprints:** O desenvolvimento segue metodologias ágeis com controlo de tarefas centralizado num painel Kanban (Trello).

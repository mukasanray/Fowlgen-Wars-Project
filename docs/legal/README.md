## 📝 Fluxo Recomendado para Novos Integrantes

1. Assinatura do **NDA** antes de receber acesso ao repositório e estratégias detalhadas.
2. Assinatura do **IP Assignment** no início da colaboração prática.
3. Preenchimento contínuo do **Third-Party Asset Disclosure** sempre que adicionar bibliotecas ou assets externos.
4. Formalização do **Founders' Agreement** caso o colaborador integre o quadro societário permanente pós-hackathon.

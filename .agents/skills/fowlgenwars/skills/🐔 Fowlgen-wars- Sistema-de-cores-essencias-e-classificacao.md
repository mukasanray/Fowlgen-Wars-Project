# 🐔 FOWLGEN WARS — Sistema de cores, essências e classificação

A ideia pode ser transformada em um sistema de identidade universal do FOWLGEN, no qual a cor é apenas a primeira camada de leitura.

- 🔴 Cor = Essência
- ✨ Símbolo = Poder
- ⚔️ Classe = Como luta
- 🗺️ Função = Onde atua
- 🧬 Espécie = O que é
- 🧠 Personalidade = Quem é

Isso permite organizar personagens, cartas, coleção, interface, habilidades, facções e até o espaço onde todos os heróis ficam dentro do jogo.

## 1. Conceito de referência

A utilização de cores para facilitar a identificação de personagens, poderes e tipos é uma linguagem visual muito difundida em entretenimento e jogos.

- Em Power Rangers, as cores funcionam como identificadores recorrentes de personagens; vermelho, azul, amarelo, verde, rosa, preto, branco, prata e dourado aparecem como categorias visuais reconhecíveis.
- Em Pokémon, a lógica vai além da cor: existem tipos e energias com identidades, características e relações próprias. O TCG associa diferentes tipos de energia a diferentes estilos de ataque, enquanto os jogos utilizam relações de força e fraqueza entre tipos.
- Pesquisas sobre associações de cores apontam padrões recorrentes: vermelho relacionado a fogo, energia e ação; azul a água e estratégia; verde a natureza e equilíbrio; amarelo a luz e agilidade; preto à escuridão e ao caos.

Essas associações são tendências culturais e perceptivas, não regras universais.

O FOWLGEN utiliza essa linguagem como referência, mas cria seu próprio sistema.

## 2. Regra fundamental do FOWLGEN

As cores não determinam sozinhas quem é o personagem.

Um personagem possui várias camadas:

🧬 PERSONAGEM

Espécie → Essência → Poder → Classe → Função → Clã/Civilização → Período/Tema → Personalidade

### Exemplo

- 🦁 Hunter
- Espécie: Galinha + Leão
- Essência: 🔴 Fogo
- Poder: Energia predatória
- Classe: Caçador
- Função: Jungle/Hunter
- Clã: Selvagens
- Tema: Tribal
- Personalidade: Instintiva, agressiva e independente

Assim, dois personagens podem ser vermelhos, mas serem completamente diferentes.

## 4. A cor não é “nível de força”

Isso é fundamental considerando a decisão que acabamos de tomar.

- ❌ Vermelho não significa mais forte que azul.
- ❌ Dourado não significa nível máximo.
- ❌ Preto não significa necessariamente personagem mais poderoso.
- ❌ Um personagem lendário não precisa possuir atributos superiores.

A cor representa:

“Que tipo de energia ou poder define este personagem?”

Enquanto a força básica de combate continua equilibrada.

### Portanto

- COR ≠ PODER TOTAL
- RARIDADE ≠ PODER TOTAL
- NÍVEL ≠ PODER TOTAL

O personagem desbloqueado já entra 100% funcional e competitivo.

## 5. Essência + classe

Aqui começa a parte mais interessante do sistema.

### Exemplos

- 🔴 Fogo + Tanque = tanque extremamente agressivo
- 🔵 Água + Assassino = personagem rápido, evasivo e controlador
- 🟢 Natureza + Suporte = curador e regenerador
- 🟣 Arcano + Mago = controle e dano mágico
- 🩶 Metal + Atirador = precisão e tecnologia
- ⚫ Caos + Assassino = personagem imprevisível, especializado em eliminar alvos

Assim, a combinação cria centenas de possibilidades sem precisar criar uma nova categoria para cada personagem.

## 7. Essência + função

A mesma essência pode aparecer em qualquer rota.

Isso preserva a estrutura que já criamos:

- Essência = de onde vem seu poder
- Classe = como combate
- Função/Rota = onde atua

### Exemplo

| Personagem | Essência | Classe | Função |
| --- | --- | --- | --- |
| Galia | 🟠 Terra | Tanque | TOP |
| Hunter | 🔴 Fogo | Caçador | JUNGLE |
| Personagem X | 🔵 Água | Mago | MID |
| Personagem Y | 🟢 Natureza | Suporte | SUP |
| Personagem Z | 🩶 Metal | Atirador | ADC |

Isso impede que o sistema fique preso a:

“Azul = suporte.”

Não. Azul pode ser qualquer coisa.

## 8. Essência + raridade

A raridade deve ser outra camada.

- ⚪ Comum
- 🟢 Incomum
- 🔵 Raro
- 🟣 Épico
- 🟠 Lendário
- 🔴 Mítico
- 🟡 Supremo

Mas:

RARIDADE ≠ FORÇA.

Uma carta lendária não precisa destruir uma carta comum.

A diferença pode estar em:

- design
- história
- animação
- efeitos
- personalidade
- dificuldade de obtenção
- exclusividade
- coleção

Isso combina com a filosofia de colecionar sem criar obrigação de grind para competir.

Cada carta do FOWLGEN pode possuir uma estrutura fixa.

```text
┌──────────────────────────────┐

│                              │

│                              │

│ 🧬 ESPÉCIE: GALINHA-LEÃO     │
│ ⚔️ CLASSE: CAÇADOR           │
│ 🗺️ FUNÇÃO: JUNGLE            │
│                              │
│ 🔥 ESSÊNCIA: FOGO            │
│ 🧠 PERSONALIDADE: INSTINTIVA │
│                              │
│ ⚔️ ATAQUE    🛡️ DEFESA       │
│ ⚡ ESPECIAL  💥 SUPREMO       │
│                              │

```

- A borda da carta pode carregar a cor da essência.
- O símbolo identifica o poder.
- O ícone identifica a classe.
- A raridade aparece separadamente.

Assim, o jogador aprende a interpretar a carta visualmente.

## 12. Clã e civilização

Representa a origem cultural, social e territorial do personagem dentro do universo FOWLGEN.

É o grupo ao qual o personagem pertence, compartilhando costumes, símbolos, arquitetura, tecnologia, vestimentas, valores, história e formas de combate.

Um mesmo clã pode possuir personagens de diferentes espécies, classes, essências e funções.

### Exemplo

- Clã: Penas Duras
- Galia — Galinha
- outro personagem — Galo
- outro — Peru
- outro — Avestruz

Eles poderiam compartilhar cultura, símbolos, armaduras e história, mas continuar tendo classes e poderes diferentes.

## 13. Origem, clã e civilização

Há um conceito importante que faltava: origem.

- Clã/Civilização = de onde pertence
- Origem = de onde veio

Assim, podemos ter:

- Galia
- Espécie: Galinha
- Essência: 🔴 Fogo
- Poder: Força/Impacto
- Classe: Tanque
- Função: TOP
- Clã: Penas Duras
- Civilização: Galinheiro Antigo
- Período: Medieval
- Personalidade: Determinada

🔥 Isso deixa o sistema muito mais poderoso.

Porque agora o jogador não estará simplesmente olhando:

“Essa carta é vermelha.”

Ele estará vendo:

- Galia
- 🐔 Galinha
- 🔴 Fogo
- 💥 Força
- 🛡️ Tanque
- 🗺️ TOP
- 🪶 Penas Duras
- 🏰 Galinheiro Antigo
- ⚔️ Medieval
- 🧠 Determinada

Ou seja:

- A cor identifica a essência.
- A classificação conta a história.

## 14. Fórmula definitiva

Eu deixaria no documento exatamente assim:

PERSONAGEM = QUEM É
ESPÉCIE = O QUE É
ESSÊNCIA = QUAL ENERGIA REPRESENTA
PODER = O QUE FAZ
CLASSE = COMO LUTA
FUNÇÃO = ONDE ATUA
CLÃ/CIVILIZAÇÃO = A QUAL GRUPO PERTENCE
ORIGEM = DE ONDE VEIO
PERÍODO/TEMA = EM QUAL CONTEXTO EXISTE
PERSONALIDADE = COMO PENSA E AGE
RARIDADE = COMO É CLASSIFICADO NA COLEÇÃO
MAESTRIA = EXPERIÊNCIA DO JOGADOR
FORÇA = PADRÃO COMPETITIVO DO PERSONAGEM

Essa é a versão que eu considero mais completa para o sistema de classificação do FOWLGEN.

## 15. Estrutura completa do FOWLGEN

PERSONAGEM → ESPÉCIE → ESSÊNCIA → PODER → CLASSE → FUNÇÃO → CLÃ/CIVILIZAÇÃO → PERÍODO/TEMA → PERSONALIDADE

Cada camada responde uma pergunta diferente:

| Categoria | Pergunta que responde | Exemplo |
| --- | --- | --- |
| PERSONAGEM | Quem é? | Galia |
| ESPÉCIE | O que é? | Galinha |
| ESSÊNCIA | Qual energia representa? | 🔴 Fogo |
| PODER | O que consegue fazer? | Explosão/força |
| CLASSE | Como luta? | Tanque |
| FUNÇÃO | Onde atua? | TOP |
| CLÃ/CIVILIZAÇÃO | De qual grupo/cultura pertence? | Penas Duras |
| PERÍODO/TEMA | Qual contexto/época representa? | Medieval |
| PERSONALIDADE | Quem ele é por dentro? | Determinada |

Isso cria um sistema de identificação rico, visual e narrativo, sem perder a clareza funcional do jogo.

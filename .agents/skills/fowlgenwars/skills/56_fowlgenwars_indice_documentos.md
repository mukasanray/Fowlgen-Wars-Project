## Convenção de nomes

- Todos os documentos Markdown desta pasta usam `nn_fowlgenwars_nome_descritivo.md`, em minúsculas, com `_` e numeração global.
- Nao usar `Prompt 01`, `Prompt 1` nem outras capitalizações no nome do arquivo.
- Novos prompts devem ser analisados contra a `SKILL.md`, os documentos de arquitetura e as decisões pendentes; nomear automaticamente com o proximo numero disponível.
- Para criar um prompt, use [`new_prompt.ps1`](../scripts/new_prompt.ps1) com `-Title "..." -Slug "..."`; revise e complete a arquitetura antes de considerar o prompt organizado.
- Se a ordem de desenvolvimento mudar, renumerar os arquivos afetados e atualizar todas as referências na mesma alteração.
